# FactoryBench

Compare AI coding factories on the same GitHub issues: what each attempt cost, how long it took, how often a human had to step in, and whether its PR got merged and stayed merged.

Factories only **report raw facts** as small JSON events over HTTP: an attempt started, an agent session used N tokens, a PR was linked, the attempt ended. FactoryBench does the rest. It prices tokens, polls GitHub for PRs, CI, reviews and merges, and computes every metric. Reporting never blocks a factory: events that fail to send are spooled and resent.

## Quick start

```bash
go build -o factorybench ./cmd/factorybench          # Go 1.27+

# operator: register a factory (prints its API token once), then run the server
./factorybench factory add my-factory --commit-email factory-bot@users.noreply.github.com --github-login factory-bot
./factorybench serve --addr :8080 --poll 3m --repo owner/product-repo

# factory: send events (always exits 0, spools on failure)
export FACTORYBENCH_URL=http://localhost:8080 FACTORYBENCH_TOKEN=<token>
./factorybench emit attempt.started --attempt a1 --key started \
  --json '{"work_item":{"repo":"owner/product-repo","issue":1},"factory_config_version":"v1"}'

# reports
./factorybench report live
./factorybench report items
./factorybench report factories
```
